This document describes the foundational visual elements of our design system.

### Color Palette
- **Primary Color:** `#388564` - Used for primary actions, key branding elements.
- **Secondary Color:** `#617d6e` - Used for secondary actions, complimentary elements.
- **Tertiary Color:** `#853e3b` - Used for accents, highlights, or specific states.
- **Neutral Color:** `#747874` - Used for backgrounds, text, and non-interactive elements.
- **Color Offer:** `#EF476F` - Used for emergency items

### Typography
- **Headlines:** `plusJakartaSans` - For all major headings and titles.
- **Body Text:** `plusJakartaSans` - For paragraphs and general text content.
- **Labels:** `plusJakartaSans` - For form labels, buttons, and small UI text.

### Shape and Form
- **Roundedness:** `2` (Moderate) - Provides a balanced, friendly feel to UI components.

### Spacing
- **Spacing:** `2` (Normal) - Establishes a comfortable and clear visual hierarchy.
